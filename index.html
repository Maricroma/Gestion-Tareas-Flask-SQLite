PFO 2 - API REST con Flask y SQLite

Descripción

Proyecto desarrollado como parte del PFO 2 para la cátedra de Programación sobre Redes de la Tecnicatura Superior en Desarrollo de Software del IFTS-29.

Consiste en una API REST desarrollada con Flask que permite registrar usuarios, iniciar sesión y acceder a una ruta protegida.

Los datos se almacenan utilizando SQLite y las contraseñas se protegen mediante hashing.

Tecnologías utilizadas

Python Flask SQLite Werkzeug Requests python-dotenv

Endpoints de la API

POST /registro

Registra un nuevo usuario almacenando su contraseña de forma segura.

POST /login

Verifica las credenciales e inicia una sesión.

GET /tareas

Ruta protegida que muestra un HTML de bienvenida.

POST /logout

Finaliza la sesión actual.

Características

  • API REST desarrollada con Flask.
  • Persistencia mediante SQLite.
  • Contraseñas almacenadas mediante hashing.
  • Autenticación mediante sesiones.
  • Variables sensibles almacenadas en un archivo .env.
  • Ruta protegida para usuarios autenticados.
  • Cliente de consola desarrollado en Python.
